## ✨ Fitur Utama KIKI v1.0
1. **Menu 1 — Peta Bakat & Peluang (Kelas XI):** Panduan *Talent Mapping* (RIASEC/16Personalities), riset pasar Google Form, analisis pesaing, perbandingan 3 ide usaha, dan pengambilan keputusan berbantuan teknologi (Metode SAW).
2. **Menu 2 — Lab Inovasi & Prototipe (Kelas XI):** Analisis 3 jenis inovasi & *Value Proposition*, panduan 5 tahap *Design Thinking* (*Empathize–Define–Ideate–Prototype–Test* + Iterasi), dan proyek pembuatan produk inovatif.
3. **Menu 3 — Proposal, Risiko & BEP (Kelas XI):** *Business Model Canvas* 9 elemen, 4 jenis risiko & 4 strategi mitigasi, perhitungan BEP otomatis langsung dari chat/kalkulator, kerangka proposal, dan simulasi tanya jawab *pitching*.
4. **Menu 4 — Pemasaran, Keuangan & Usaha Hijau (Kelas XII):** Komersialisasi, bauran pemasaran 4P & CTA, pengelolaan keuangan (modal, arus kas, HPP, harga jual, laba rugi), budaya korporasi, evaluasi PDCA/Kaizen, dan *Green Business Plan* (3R, CSR, *Triple Bottom Line*).
5. **Menu 5 — Kalkulator & Contoh UMKM Sulawesi Selatan:** Kalkulator BEP (pembulatan ke atas), Kalkulator HPP & Margin, Simulator Pembobotan SAW, serta studi kasus UMKM lokal Sulsel per jurusan SMK.
6. **Menu 6 — Kuis RPP & Refleksi:** **109 soal Pilihan Ganda resmi** dari 13 RPP KIK lengkap dengan pembahasan otomatis, skor ketuntasan (≥75), dan Refleksi *Traffic Light* (🟢🟡🔴).
7. **Rangkuman Siap Salin & Guardrail Keamanan:** Fitur salin/unduh `.txt` untuk ditempel ke LK/Canva/Google Docs, guardrail tolak data pribadi sensitif, dan prinsip *memandu, bukan mengerjakan tugas murid*.
8. **Dual-Engine AI:** Berjalan 100% gratis tanpa kuota habis dalam **Mode Mandiri (Basis 13 RPP)**, serta mendukung **Mode Generatif Gemini API (Opsional/BYOK)** langsung di browser.

## 🚀 Cara Publish ke GitHub Pages (5 Langkah Mudah)

Aplikasi ini **100% statis (HTML, CSS, JavaScript)** sehingga langsung berjalan di GitHub Pages secara **GRATIS selamanya** tanpa server tambahan:

1. **Buat Repository Baru di GitHub:**
   - Masuk ke [github.com](https://github.com) → klik **New Repository**.
   - Beri nama repository, misalnya: `kiki-asisten-ai-wirausaha` (pilih **Public**).
2. **Unggah Semua File di Folder `kiki-ai-agent/`:**
   - Cara termudah lewat browser: klik **Add file → Upload files**, lalu seret seluruh isi folder `kiki-ai-agent/` (`index.html`, `styles.css`, `.nojekyll`, `README.md`, folder `data/`, dan folder `js/`) → klik **Commit changes**.
   - Atau lewat terminal Git:
     ```bash
     cd kiki-ai-agent
     git init
     git add .
     git commit -m "Rilis KIKI v1.0 - Asisten AI Wirausaha Muda SMKN 2 Makassar"
     git branch -M main
     git remote add origin https://github.com/USERNAME_GITHUB_ANDA/kiki-asisten-ai-wirausaha.git
     git push -u origin main
     ```
3. **Aktifkan GitHub Pages:**
   - Buka tab **Settings** pada repository Anda → pilih menu **Pages** di sebelah kiri.
   - Pada bagian **Build and deployment → Source**, pilih **Deploy from a branch**.
   - Pilih Branch: **`main`** dan folder: **`/ (root)`** → klik **Save**.
4. **Tunggu 1–2 Menit:**
   - Muat ulang halaman *Pages*; tautan publik Web App KIKI Anda akan muncul di bagian atas, berbentuk:
     `https://USERNAME_GITHUB_ANDA.github.io/kiki-asisten-ai-wirausaha/`
5. **Bagikan ke Murid & Tempel Tautan pada LK-5 / LK-6:**
   - Tautan tersebut langsung bisa dibuka murid melalui HP Android/iOS maupun laptop tanpa instalasi, dan dapat dibuatkan Kode QR untuk ditempel di kelas!
